# Experimental methodology

The pilot is a balanced randomized block design: four workload classes, WSL process and Docker Desktop, interference none or workload-matched, ten blocks with every condition once per block. The manifest seed fixes ordering. Trial IDs identify a condition within a block; conditions include canonical manifest factors. Warmup is a separate workload invocation with preserved logs; cooldown separates trials. Fixed-duration throughput is the primary response: events/s (CPU), MiB/s (memory and disk), Mbit/s (network). Duration checks detect incomplete work and are secondary QC, not fixed-work latency.

The estimand is the change in throughput for a specified execution environment and interference treatment. Within-backend interference contrasts are preferable to Docker/WSL stack contrasts. Matched interference differs physically for each workload and must not be treated as one common cross-workload treatment. Resource limits, filesystem and loopback topology are recorded. Local CPU affinity differs from Docker quota enforcement. Docker named volumes and local scratch have different storage paths, so disk backend effects remain confounded.

Analysis uses independent trials, never metric samples, as n. Condition means receive deterministic 5,000-resample bootstrap intervals when n>=5. Slowdown is baseline-process/no-interference throughput divided by treatment throughput, paired by block, with a bootstrap CI across matched blocks. Values >1 indicate lower treatment throughput. Comparisons and inference stay within each workload. P95/P99 are across independent trial throughput values and require >=30 valid trials; per-operation latency fields remain absent unless a parser supports appropriate samples.

For complete factorial cells with >=5 trials/cell and >=30 total trials, fit log throughput to backend, interference, their interaction and block fixed effects. Require residual degrees of freedom >=8. Report type-II ANOVA partial eta squared (term SS / term-plus-residual SS), HC3 coefficient CIs, Shapiro residual and Levene variance diagnostics. Benjamini-Hochberg adjusts factor-term p-values across fitted workload models. Diagnostics can indicate that inference needs a preregistered permutation or hierarchical sensitivity analysis; the current pipeline does not automatically substitute one. Interactions require conditional interpretation. Effect sizes describe the experimental design, not virtualization-layer percentages.

QC retains failed, timed-out, cancelled, invalid and unsupported attempts and scheduled missing trials. Parser errors, nonpositive units, short duration and lost interference invalidate a trial. More than five median absolute deviations marks an anomaly but does not exclude it. No post-hoc performance-based exclusions. Record sampler missing rate and block balance; inspect version discrepancies, engine identity and resource enforcement before accepting comparisons.

Valid threats include Windows host activity, thermal variability, power state, NUMA/SMT topology, guest quota sharing, filesystem/cache state, Docker engine context, different benchmark packages, monitoring overhead, single-session drift and loopback routing. The pilot is screening evidence. Before confirmatory work, pin image digests, match benchmark versions, measure sampling-on/off overhead in paired randomized campaigns, preregister selected outcomes and gather >=30 trials per selected condition across sessions. Session effects currently require separate campaign analysis; no cross-run pooling is performed.
